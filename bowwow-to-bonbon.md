You can try Bon Bon here 

I had some time over weekend to see about how to push card decks via open web standards as proposed by Dave Winer.  I am waiting on a windows verson of BonBon.   I've recently been enjoying writing and developing using github repositories with AI.

So I wanted to see if I could send a closed proprietary collection of cards that were going to be timestamped at some time in future as 'collectible'   could some or most of that info travel indifferent form across the net.  So I 
    
*   Created a live FanVault drop named **First Automated Dot**, containing three collectible card designs.
    
*   Published a public three-card collection on GitHub Pages.
    
*   Published the collection in Markdown (`.md`), JSON, and OPML.
    
*   Created a separate Markdown story, **Hello World! I'm Little Pixel**, featuring a rainbow 🌈, fish 🐟, and JOIN DROP hyperlink.
    
*   Published a static RSS feed on GitHub Pages.
    
*   Subscribed to that feed using Dave Winer's FeedLand.
    
*   FeedLand successfully retrieved and displayed the RSS announcement, including Unicode characters and emojis.
    
*   The FeedLand announcement linked to our public GitHub Pages collection. The direct JOIN link in the announcement was not clickable in our test.
    
*   Opened Little Pixel's `.md` file in Dave Winer's BonBon Markdown browser.
    
*   BonBon displayed the story with formatted text, Unicode characters, and working hyperlinks.
    
*   Clicked JOIN DROP in BonBon and successfully reached the live FanVault drop.
    
*   No changes to the FanVault Game or database were required for these publishing tests.

Results and limitations
-----------------------

*   **Confirmed:** Public Markdown files can be read and formatted by BonBon.
    
*   **Confirmed:** FeedLand can subscribe to and display our GitHub Pages RSS feed.
    
*   **Confirmed:** Unicode characters, including rainbow, hearts, and fish, displayed correctly in both readers.
    
*   **Confirmed:** BonBon's JOIN hyperlink opened the correct FanVault drop.
    
*   **Confirmed:** FeedLand's announcement title opened the public collection page.
    
*   **Not working in this test:** Direct JOIN hyperlink inside FeedLand's announcement.
    
*   **Not yet tested:** Adding a second RSS item and verifying automatic discovery by existing subscribers.
    
*   **Not yet implemented:** Automatic RSS generation when a FanVault deck goes Live.
    
*   **Not established:** Transfer or import of actual collectible card ownership between independent applications.
    

Observation
-----------

A FanVault deck can have a public description and JOIN invitation distributed through ordinary web publishing formats.

Markdown provides a readable document. JSON provides structured metadata. OPML provides an outline of the collection. RSS announces the publication. Independent readers can retrieve and display those resources.

FanVault remains responsible for the actual Game, card issuance, and participation.

**Experiment 001 demonstrated interoperability for publishing, discovery, reading, and linking—not portability of card ownership.**
