I've been following [Dave Winer's work on BonBon](https://demo.bonbonweb.org/), his new Markdown browser and vision for a web built around writers and readers. It got me thinking about some experiments to use the open web to announce a FanVault drop of three collectible cards, one little collection, published using ordinary web standards including Markdown, JSON, and OPML.

[Dotland](https://fanvaultlive.github.io/), our open-web playground for FanVault.Live, we started with [Experiment 001 — First Automated Dot](https://fanvaultlive.github.io/dotland/experiment-001/) and used Feedland to announce it.

[Feedland](<img width="500" height="315" alt="112326_02" src="https://github.com/user-attachments/assets/0a8281a4-072d-48de-b560-72a001dc8e5d"/>)

So I have been thinking I want to use .md for card text in next release so I wrote a little loader to handle .md.  The second part I made available for anyone that wants to create a url from .md document and try it in bon bon or share the public url.  

**[Markdown Publish Lab](https://markdown-publish-lab-preview-b80eovykz-brianpucketts-projects.vercel.app/)** where you can upload a `.md` file, preview it, click Publish, and get a public link to share. No elaborate publishing system required.  And I put a link to load it in Bon Bon so people can try a demo of Dave's Bon Bon browser.
